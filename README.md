# Online Food Delivery Project Documentation

## Project Overview
The Online Food Delivery project allows users to order food from their favorite restaurants through a seamless online platform. The platform is designed to enhance user experience, making food ordering quick and efficient.

## Features
- **User Registration and Authentication**: Users can register, login, and manage their profiles.
- **Restaurant Listings**: Users can browse restaurants based on cuisine, ratings, and location.
- **Online Payments**: Secure payment processing for user orders.
- **Order Tracking**: Real-time tracking of orders from preparation to delivery.
- **Admin Dashboard**: Restaurant admins can manage menu items, view orders, and promote offers.

## Tech Stack
- **Frontend**: React.js, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Deployment**: Heroku / AWS

## Installation Instructions
1. **Clone the repository**: `git clone https://github.com/kvithya368-prog/online-food-delivery.git`
2. **Navigate to the server directory**: `cd online-food-delivery/server`
3. **Install dependencies**: `npm install`
4. **Start the server**: `npm start`
5. **Navigate to the client directory**: `cd ../client`
6. **Install dependencies**: `npm install`
7. **Start the client**: `npm start`

## Usage Guide
1. Open the browser and go to `http://localhost:3000` to access the application.
2. Register or log in to your account.
3. Browse the list of restaurants and select your preferred items.
4. Add items to your cart and proceed to checkout to place your order.
5. Track your order status in real-time.

For any issues, please check the documentation or report on the GitHub issues page.
